# 03: Demolition Project source records

**What to build:** Staff can maintain Demolition Project source records so recovered materials can be traced to the project where they originated.

**Blocked by:** None (can start immediately).

**Status:** complete

- [x] A Demolition Project receives a unique sequential `DEM-` code.
- [x] Staff can create and update a project with a name, site/location, required start date, and optional end date; an end date cannot precede the start date.
- [x] Project records are available to recovered-material workflows as traceable sources.
- [x] Managing Demolition Project and recovery records is separately permission-gated from viewing inventory and recording stock movements.
