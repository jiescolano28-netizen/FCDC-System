# 08: Isolated, Visibly Marked Demo Environment

**What to build:** Users can explore demo examples in a clearly identified demo environment without demo activity contaminating production records, operational totals, or exports.

**Blocked by:** 03: Persisted Inventory Management and Selling Prices; 04: Paid Cash or Card Checkout; 06: Indicative VAT Summaries; 07: Persisted Operational Dashboard and Sales Reports.

**Status:** ready-for-agent

- [ ] Demo mode is visibly distinguished from production in the user interface.
- [ ] Demo records are isolated from production activity, totals, reports, VAT summaries, and exports.
- [ ] Production flows do not import illustrative browser fixtures as real transactions.
- [ ] Feature coverage verifies the visible demo distinction and production exclusion behavior.
